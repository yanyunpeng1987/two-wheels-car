1. 确认HC-05D实物、载板供电和接线，验证ROLE3、9600/8N1、服务/特征属性及断电保持。
2. 核对手机当前包/证书后安装组合v24，验收启动/固定机型/信息页及退出重进。APK打包和静态字节码通过不能替代ART验证。

4. 500ms为收到有效CMD3后的有效期，不是物理停车时间；控制循环延迟、30分钟遥测、真实范围及实际栈峰值尚待验证。新MAP已变化，不沿用T4的RAM诊断绝对地址。
