# 20BC:5500新九字节手柄实测（FW-HID-004，2026-10-13）

用户接入5只新型号接收器，完成其中一只手柄的PC标定。本记录保留10月13日格式家族和标定范围；r4首帧故障及后续诊断见[历史阶段记录](../releases/2026-10-13-new9-gamepad.md)。10月14日同连接实验确认辅助IN83必须持续读取，正式r5已烧录、单只车端输入台架验证通过，当前进度见[r5记录](../releases/2026-10-14-gamepad-r5.md)。这是2.4G USB接收器，不涉及蓝牙或手机APP。

## 五只接收器的描述符

A～E产品字符串均为Twin USB Joystick，VID20BC/PID5500/bcdDevice1003；EP0最大包64、配置总长度84字节，接口class/subclass/protocol均3/0/0。

| 接口 | 用途 | Interrupt IN | 最大包 | 轮询 | 报告描述符 |
|---|---|---|---|---|---|
| 0 | Game Pad | 81 | 64字节 | 10ms | 123字节 |
| 1 | Game Pad | 82 | 64字节 | 10ms | 123字节 |
| 2 | 系统/用户控制 | 83 | 64字节 | 10ms | 101字节 |

10份Game Pad报告描述符已保存原始字节且完全相同，SHA-256 `d29e4773001992e3607770f668d32b27bee2f02508bb4633f699be42f0f17106`。Windows输入长度10、Report ID0；前导零是Windows占位，不进入实际9字节USB载荷。接口2不用于小车输入。

此前[2026-09-17设备记录](20bc-5500.md)的元数据与本次相同，元数据不能识别物理新旧接收器。新profile4适用于这组已测64/123格式；旧FW-HID-001仍暂停，其物理按键和本轮表现未重新验证。

## USB载荷与物理标定

字节偏移从USB载荷0开始；中位为 `00 00 0F 80 80 80 80 00 00`。

| 字节 | 描述符字段 | 本次解释 |
|---|---|---|
| 0/1低15位 | Button Usage1～15 | 仅映射已标定的7～12；15个原始位均参与松键判定，bit15填充排除 |
| 2低四位 | Hat0～7，支持Null | 上0、右2已操作；8～15按中位处理；其余方向由软件布局检查覆盖 |
| 3/4 | X/Y | 实测左杆水平/垂直 |
| 5/6 | Z/Rz | 实测右杆水平/垂直；不同于旧八字节profile的byte6/5 |
| 7/8 | C5/C4，各8位 | 不接入动作，也不当作已证实的无线连接标志 |

用户完成18项标定，实际动作端点为 **A/MI_01**。X使用raw−128，Y使用128−raw，输出限制−127～127，128为中位。

| 动作 | 实际USB报告 |
|---|---|
| 左杆前 | `00 00 0F 80 00 80 80 00 00` |
| 左杆后 | `00 00 0F 80 FF 80 80 00 00` |
| 左杆左 | `00 00 0F 00 80 80 80 00 00` |
| 左杆右 | `00 00 0F FF 80 80 80 00 00` |
| 右杆前 | `00 00 0F 80 80 80 00 00 00` |
| 右杆后 | `00 00 0F 80 80 80 FF 00 00` |
| 右杆左 | `00 00 0F 80 80 00 80 00 00` |
| 右杆右 | `00 00 0F 80 80 FF 80 00 00` |

| 按键 | 原始Usage | 原有动作位图 |
|---|---|---|
| L1 | 7 | 4000 |
| R1 | 8 | 8000 |
| L2 | 9 | 0001 |
| R2 | 10 | 0002 |
| SELECT | 11 | 0004 |
| START | 12 | 0008 |

START沿用现有提示音功能，不能描述成停车键。页面标记的另两个面键操作分别产生Usage14/15，未给它们绑定动作或PID修改，也不从页面命名推断外壳真实功能。Usage1～6/13～15均不映射动作。

## 软件行为与范围

r4枚举时同时要求20BC:5500/bcd1003、端点64和描述符123来选择profile4；不是通用HID描述符解析器，也未在运行时用描述符SHA鉴别每一个字段。接收只接受实际9字节，接口0/1独立缓冲，复用r3互斥控制和每路500ms有效报告期限。第三接口不参与控制，未新增USB Hub或5接收器同时接入能力。

原始资料存于忽略目录 `build/new-model-evidence/`，包括inspection、5组二进制描述符与标定JSON。PC标定JSON SHA-256为 `6366afae44230cb85783066d409a32724746d822677c8b2cc249021874188b36`。私人设备路径和身份标识不写入此文档。

只有A/MI_01得到完整物理动作标定。B～E没有逐项操作证据；E两个接口在后续采样期间断开。描述符一致不等于五只按键、射频、关机或车端功能已通过。PC有重复中位及保持动作帧，车端r4则只有每路首帧，故持续接收、四向/回中和物理关机均需按[后续验收](../releases/2026-10-13-new9-gamepad.md#fw-hid-004后续验收)完成。
