# T4 电压滤波与低压提示验证

关联需求：FW-VOLT-001。以用户持续自稳正常的T3为基线。

## 现象与证据

用户反馈自稳持续正常，但偶尔两声短鸣，电压均值约11.9V。
T3只读RAM快照记录电压11.83V、flag_move=1、Normal模式；最后蜂鸣1000Hz、50ms响/50ms停、2次，低压报警timer非零。
这说明低压状态机曾触发，不能单凭声音区分ADC读数毛刺、真实电源短暂跌落或同音型按键双击。
本次增强抗瞬时波动能力，不把干扰源认定为已定位。

## T4行为

- 每约100ms在主循环完成一笔电池ADC转换，和CCD读取串行；平衡中断不访问ADC1。
- ADC先Stop、配置电池CH4，再Start；EOC等待用DWT计数差限1ms。先检查完成再检查超时，控制中断抢占后若已转换完成仍接受。
- 所有HAL错误均返回无效；退出时停止ADC并恢复CCD的CH10/15cycles。没有增加多次同步批量采样。
- 连续3笔新有效采样预热，取最近3笔中值，不叠IIR。滤波值低于9.0V持续至少1秒才确认低压；达到9.5V持续至少1秒才解除。
- 确认低压后每约1秒两声短鸣。中值窗口和确认时间带来额外响应时间，不能将1秒理解为从物理电压变化起严格1秒。
- 无效采样或相邻采样间隔>350ms打断中值和待确认时间。有效样本超过500ms未更新则过期；过期/不足3笔新数据不触发蜂鸣，且不假装低压已经恢复。
- 沿用旧程序排除<=5V的范围检查，改为显式range_error记录、显示不可用；已确认低压状态保留。该条件不表示真实<=5V是安全状态。超过ADC理论量程的样本同样无效。
- 新定时均使用DWT原始uint32周期差，支持约51秒计数回绕，不修改全局HAL_GetTick或原蜂鸣器播放时基。

## 保留T3行为与显示

右TIM2滤波保持15、左TIM3保持10；PID、SPD门限、编码器换算、运动/启停逻辑未改变。
`voltage`仍发布最新成功转换的原始电压，供原SPD的11V分支、蓝牙CMD7和停机快照使用；转换失败保留上次成功值。
LCD正常页显示单独的中值滤波电压；确认低压时追加LOW，数据不可用显示“Voltage: --”。停机页V@stop仍是当时原始电压。
滤波只服务显示与低压提示，未把滤波电压替换进SPD判断。通讯帧格式、字段单位和电机控制参数不变。

## 诊断

全局battery_monitor由main独占。保存16笔原始/滤波样本、有效性及时间戳，采样/ADC错误/范围错误/低原始值计数、有效原始最小/最大值、低压周期数、报警次数及last_alarm快照。
`low_raw_count`包括ADC读取成功但<=5V的范围异常；min/max只统计允许范围样本。history跨错误/过期保留，便于只读取证。
若再听到两声短鸣，可比较alarm_count是否增加；不增加时需查按键/手柄/外部模块提示，不应继续盲改电压门限。

## 验收

1. 原生C验证：单点/两点毛刺不报警；持续有效低压仍报警；恢复滞回、重复样本、错误、过期和计数回绕正确；ADC每个失败路径清理并恢复CCD。
2. 实机启动后确认T4、Flash向量完整、PG关闭、PID保持、右左编码器滤波保持；读取battery_monitor确认采样推进、ready=1且无持续ADC错误。
3. 相同平地自稳条件继续测试：电压显示稳定、无瞬时误报，T3的停止问题不复发。分别记录蜂鸣及其alarm_count/last_alarm，不能只凭安静就认定ADC工作正常。
4. 再做运动/转弯、受控拿起保护和需要的CCD模式回归。持续真实低压的硬件验证需另行受控安排；主机测试不能替代实车电源波形。
